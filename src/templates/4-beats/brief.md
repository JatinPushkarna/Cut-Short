# 4 Beats -- template brief

Built 2026-08-10 in response to a real Instagram viewing pattern: repeated
drop-off during the Bridge beat across posts using '5 Beats'. Not a single
day's number -- an observed pattern across multiple posts.

## Beat structure
Hook, video, reveal, CTA

## Hook style
Same as '5 Beats': dimmed/blurred still, glitch-style text entrance. Real
footage still withheld until the hook has earned attention -- that part of
'5 Beats' is proven (Day 2's 3x lift) and isn't what's being changed here.
Only the Bridge beat is cut; the hook cuts straight to the video beat.

## Reuse decisions
Hook, CTA, reveal/verdict stamp (RedFlagStamp), hook-to-video transition
(GlitchFlash), theme -- all reused unchanged from '5 Beats'. No new
component code; only the beat order changes (Bridge removed).

## Other structural rules
Now the default template for new projects/content -- see
`cli/commands/design-content-structure.ts`'s template-decision prompt.
'5 Beats' (with Bridge) stays available as a named template for when a
deliberate misdirect beat genuinely fits a specific piece of content.
